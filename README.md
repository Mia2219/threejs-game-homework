# 3D躲避方块小游戏
## 项目简介
基于Three.js开发的3D网页躲避小游戏，玩家操控角色躲避垂直落下的方块障碍物，所有游戏物体固定在同一个平面上，不会前后错落。

## 游戏操作
- ← 左方向键：角色向左移动
- → 右方向键：角色向右移动
- 点击开始按钮启动游戏

## 游戏规则
1. 方块从上方缓慢垂直下落，按顺序一个一个生成，方块不会旋转
2. 左上角实时展示分数、剩余命数
3. 一共有3次碰撞机会，三次全部用完游戏结束
4. 方块成功落到地面，获得分数
5. 碰撞后角色会短暂无敌闪烁，防止连续扣血

## 技术说明
- 使用Three.js 3D库渲染场景
- 网格地面，平视固定相机
- 所有角色、障碍物Z坐标锁定为0，保持共平面
- CDN引入three.min.js，不需要本地额外安装依赖

## 运行方式
1. 将html文件直接在浏览器打开，或者用VS Code的Live Server插件运行
2. 仓库为公开仓库，直接上传html和md两个文件即可提交作业
